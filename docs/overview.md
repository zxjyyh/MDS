# 项目概述

## 定位

内业管理系统是一套面向中小型机构的**内业资料综合管理平台**，用于集中管理人员档案、设备台账、各类证照证书及其有效期，并在证件临近到期时自动预警和邮件提醒。

系统前后端一体化打包为**单个可执行文件 / 单个容器**，不依赖外部数据库和中间件，适合在局域网、办公 PC 或家用 NAS 上私有化部署。

## 核心功能

| 模块 | 功能描述 |
|---|---|
| 人员管理 | 人员档案建档、多类证照有效期管理、证件影印件上传与在线预览 |
| 设备管理 | 设备台账管理、检定/校准有效期跟踪、检定证书归档 |
| 文件系统 | 统一的文件上传 / 下载 / 预览（图片、PDF、DOCX） |
| 体系文档 | 资质体系文档与安全生产文档的树形分类管理 |
| 仪表盘 | 全模块证件到期自动统计（已过期 / 30 天 / 60 天 / 90 天四级预警） |
| 到期提醒 | 每日定时扫描 + SMTP 邮件通知 + 手动触发 |
| 用户管理 | 多用户、角色权限（管理员 / 普通用户） |
| 系统设置 | SMTP 邮件配置、提醒规则自定义 |

## 技术特点

- **零依赖部署**：SQLite（`modernc.org/sqlite`，纯 Go 实现，无需 CGO）+ 前端产物内嵌，运行时只需一个二进制文件。
- **单容器交付**：多阶段构建，最终镜像基于 Alpine，体积约 25 MB。
- **NAS 友好**：支持 `PUID`/`PGID` 运行时降权，解决 bind mount 文件属主不匹配问题。
- **开箱即用的安全默认值**：随机管理员初始密码、随机 JWT 密钥、CORS 默认不放行跨域、上传文件内容嗅探白名单。

## 首次登录

系统首次启动会自动创建管理员账号 `admin`：

- **密码不硬编码**。默认随机生成 12 字节强口令，**仅在控制台 / 容器日志中打印一次**。
- 也可在启动前设置环境变量 `ADMIN_INIT_PASSWORD` 指定初始密码。

登录后请立即在「用户管理」中修改密码。

## 数据存放

| 路径 | 内容 | 是否必须持久化 |
|---|---|---|
| `data/data.db` | SQLite 数据库（含全部业务数据） | 是 |
| `data/.secrets.env` | 自动生成的 JWT 密钥（0600） | 是 |
| `uploads/` | 上传的证件、证书原件 | 是 |
| `logs/` | 运行日志 | 否 |

备份时只需复制 `data/` 与 `uploads/` 两个目录。
